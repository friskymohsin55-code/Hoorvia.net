Push Pull Legs Split Chart: Printable 6-Day Workout Plan

Print our push pull legs split chart: a 6-day PPL workout with main lifts, accessory work, and sets and reps for every training day.

Push, pull, legs is the simplest training split that actually works: every muscle gets hit twice a week, each session has one clear job, and nothing overlaps enough to stall recovery. Push day trains chest, shoulders, and triceps; pull day trains the back and biceps; legs day trains quads, glutes, hamstrings, and calves. Run the three days twice, rest on day seven, and repeat — six sessions a week, each lasting about an hour. The trap is loading every day like a max-effort test: the split only works when the first lift is heavy and the accessories stay controlled, so you can recover before the same muscles are hit again three days later. This printable chart lays out all six training days with the main lifts, the accessory work, and the sets and reps for each. Frequently Asked Questions

How many days a week is a push pull legs split?▼

The classic PPL split runs six days a week: push, pull, and legs, then the same three days again, with one rest day. A three-day version works too — run each day once per week — but the six-day version is what gives every muscle two sessions a week.

Can beginners use a push pull legs split?▼

Yes, if the weights stay moderate and the focus stays on form. Beginners often do better on the three-day version first, learning the barbell lifts with lighter loads before moving to six days. Add weight slowly and skip the second round of each day until recovery keeps up.

What is the best rest day on a PPL split?▼

Take day seven off after the second legs day, so every muscle group gets a full day before the cycle restarts. If life gets in the way, any missed day simply shifts the cycle — never train the same muscles two days in a row to catch up.
