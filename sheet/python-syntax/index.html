💡 Quick Tips

Indentation Rule: Python uses 4 spaces (never mixed tabs and spaces) per indentation level to define code blocks instead of curly braces.

Mutable Default Trap: Never use def add_item(val, items=[]): as a default argument; use items=None and initialize items = [] inside the function body so lists do not persist across calls.

Frequently Asked Questions

What is the difference between a list, a tuple, and a set in Python?

Lists ([1, 2]) are ordered and mutable, allowing you to add or change elements. Tuples ((1, 2)) are ordered but immutable once created. Sets ({1, 2}) are unordered collections that automatically strip duplicate values and support ultra-fast membership checks.

Why should I use enumerate() instead of range(len(my_list)) in Python loops?

Using for i, item in enumerate(my_list): gives you both the index and the actual value directly without manual indexing (my_list[i]). It is faster, cleaner, more Pythonic, and lets you set a custom starting counter number.

How do *args and **kwargs work in Python function definitions?

*args collects any number of extra positional arguments into a tuple, while **kwargs collects extra keyword arguments (key=value) into a dictionary. Together, they let you write flexible functions and decorators that accept variable inputs.
