Terminal Commands: Printable Cheat Sheet

The terminal looks intimidating until you learn twelve commands: pwd tells you where you are, ls shows what is there, cd moves you around, and cp, mv, and rm handle files. Everything else is a variation — grep searches inside files, find locates them by name, and chmod makes a script executable. Tab completion finishes filenames for you, so you rarely have to type a long path by hand. The trap is rm: it deletes without a recycle bin, and rm -rf on the wrong folder is unrecoverable. Always double-check the path, and use ls before you delete. This printable chart lists the twelve essential terminal commands with what each does, an example, and the note. Consult the live reference table below, or print the sheet and keep it by your keyboard.

💡 Quick Tips

ls before you delete: Run ls on the path first to see exactly what rm will remove. Deleting the wrong folder has no undo.

Use tab completion: Type the first letters of a filename and press Tab — the terminal finishes it. It is faster and prevents typos in long paths.

Frequently Asked Questions

What is the difference between cp and mv?

Cp copies a file and leaves the original; mv moves it, so the original is gone. Mv also renames — mv old.txt new.txt changes the name in place. Both need -r to work on folders.

How do I undo a deleted file in the terminal?

You cannot — rm deletes permanently, with no recycle bin. That is why you ls the path first, and why important files belong in version control or a backup, not just on disk.

What does chmod +x do?

It makes a file executable, so you can run it as a program — ./script.sh instead of sh script.sh. Without the executable bit, the shell refuses to run it, and you get a permission denied error.
