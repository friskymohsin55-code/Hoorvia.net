How to Use This Chart

Pin this chart where you work: it packs 4 entries and 4 columns (Command / Feature, Syntax / Keyboard Shortcut (Win / Mac), Operational Context & Environment, Key Output / Practical Result) into one printable page, built for quick lookups.

Scan down the Command / Feature column to your item, then read across for Syntax / Keyboard Shortcut (Win / Mac), Operational Context & Environment.

Example: for Styles Primary Action, the chart gives Syntax / Keyboard Shortcut (Win / Mac) of Ctrl + P / Cmd + P.

  • Compare values down a single column to spot the pattern before you commit to a choice.
  • When two rows look close, the Key Output / Practical Result column usually breaks the tie.
  • Print it once and keep it where you work — that's the whole point of a cheat sheet.
