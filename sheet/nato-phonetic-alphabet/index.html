NATO Phonetic Alphabet Chart: Printable Code Word Reference

Spelling your name over a bad phone line is a comedy of errors — ‘M as in... uh, Mike? No, N as in Nancy?’ — and in aviation, shipping, or emergency calls, that confusion is not funny at all. The NATO phonetic alphabet solves it with one unambiguous code word per letter, tested so speakers of any language pronounce and recognize each word the same way. Alpha (officially spelled Alfa), Juliett with a double t, and the rest of the twenty-six were chosen so no two sound alike, even through static. This printable chart lists every letter with its official ICAO code word and pronunciation, plus a quick example for drilling. Consult the live reference table below before your next call, or print the sheet below and keep it at your desk — after a week of use, spelling ‘Kilo-Oscar’ instead of stumbling over K and O becomes second nature.

💡 Quick Tips

Say the Word, Not the Letter: Pair letter and word — ‘M as in Mike’ — so listeners catch the code word every time.

Pronounce the Odd Spellings: Alfa is AL-fah, Juliett ends with a clear T, Quebec is keh-BECK — the official ICAO sounds, not English guesses.

Drill with Real Names: Spell your name, street, and order numbers with the chart for a week; muscle memory replaces the old habit.

Frequently Asked Questions

Why is it Alpha in the military but Alfa in the official list?

The official ICAO spelling is Alfa with an F, because in many languages ‘ph’ is not pronounced as an English F — the spelling removes that ambiguity. US military writing commonly uses Alpha, and both are understood everywhere. The chart uses the official ICAO spellings so you learn it right.

When should I use the NATO phonetic alphabet?

Any time you spell names, addresses, passwords, booking codes, or order numbers over the phone or radio — customer service calls, travel bookings, military and aviation radio, and emergency dispatch. If the other person asks you to repeat yourself twice, switching to code words ends the confusion instantly.

Is there a NATO phonetic alphabet for numbers too?

Yes — the digits 0–9 have official code words: Zero, Wun, Too, Tree, Fower, Fife, Six, Seven, Ait, Niner. Several are deliberately mispronounced (Tree, Fife, Niner) so they cannot be confused over a noisy radio. This chart covers the 26 letters; the digits follow the same system.
