VLOOKUP Guide: Printable Excel Lookup Chart

VLOOKUP is the most-used function in Excel: give it a value, a table, and a column number, and it finds the match. Its limits are famous — it only looks right, it breaks when a column is inserted, and a missing value returns an ugly #N/A. The modern replacements fix all three: XLOOKUP looks in any direction and takes a fallback value, INDEX/MATCH survives column inserts, and FILTER returns every match at once. The trap is the exact-match flag: leave it off and VLOOKUP returns the nearest value below, which is almost never what you wanted. Always use FALSE for an exact match. This printable chart lists twelve lookup functions with syntax, use case, and the error guard. Consult the live reference table below, or print the sheet and keep it by your spreadsheet.

💡 Quick Tips

Always use FALSE for exact match: VLOOKUP without FALSE returns the nearest value below — almost never what you wanted. Use FALSE for an exact match, every time.

Wrap lookups in IFERROR: A missing value returns #N/A and breaks every formula downstream. IFERROR turns it into a friendly message or a zero.

Frequently Asked Questions

Why does my VLOOKUP return #N/A?

The lookup value is not in the first column of the table — a typo, a trailing space, or a number stored as text. Check the value exists, trim the spaces, and make sure numbers are numbers, not text.

What is the difference between VLOOKUP and XLOOKUP?

VLOOKUP only looks right and breaks when a column is inserted; XLOOKUP looks in any direction, takes a fallback value for missing matches, and does not need a column number. XLOOKUP is the modern replacement — use it when your Excel version supports it.

Can VLOOKUP look to the left?

No — VLOOKUP only searches the first column and returns a value to its right. To look left, use INDEX/MATCH or XLOOKUP, which have no direction limit and can return a value from any column in the table.
