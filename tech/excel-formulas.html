How to Print & Use This Chart

Print on US Letter or A4 and keep it beside your keyboard, or pin it to a cubicle wall where you can glance at it without switching windows. Use “Save as PDF” in the print dialog for a PDF copy in Letter or A4, and laminate it if your desk gets coffee rings — this is a sheet you will reach for daily in the first weeks of learning formulas. A second copy in a notebook is useful for remote work days, when the office wall chart is not beside you. Print it in colour if you can, but it remains readable in black and white because the structure is in the table, not the colour.

To use a formula, type it exactly as shown, then replace the example cell references with your own range — the pattern matters more than the letters. Lock a lookup table with dollar signs ($D$1:$E$20) before copying a formula down a column, or your range will drift row by row and return wrong results. Prefer XLOOKUP over VLOOKUP for new work: it handles lookups to the left, needs no column number, and has a built-in “not found” message. Wrap risky divisions and lookups in IFERROR so a spreadsheet shows a clean dash instead of #DIV/0! or #N/A to a manager. Test every new formula on a small sample first, check one result by hand, and only then copy it across thousands of rows — a fast wrong answer is worse than a slow right one.

Frequently Asked Questions (FAQs)

VLOOKUP or XLOOKUP — which should I learn?▼

XLOOKUP for new work: it is simpler, works in both directions, and handles missing values cleanly. Learn VLOOKUP too, because older files still use it.

Why does my copied formula give wrong results?▼

Usually a range drifted because it was not locked with $. Use $ before the column/row you want fixed when copying.

How do I avoid #N/A errors?▼

Wrap the lookup in IFERROR, e.g. =IFERROR(XLOOKUP(...),"Not found"), or check that the lookup value exactly matches, including spaces.

Can I use these in Google Sheets too?▼

Mostly yes — SUM, IF, COUNTIF, VLOOKUP and XLOOKUP work similarly, though some functions differ slightly. See the Google Sheets sheet on this site.
